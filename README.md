# LaboratoryStart
Файлы, которые использовались для проверки работоспособности:

App.vue (frontend/src/App.vue), index.html (frontend/index.html), api.php (backend/routes/api.php).

| FRONTEND – Vue.js;
BACKEND – Lavarel |

Сборка данного проекта может занять от 5-20 минут

Шаги для работы:
1. Перейти в директорию с проектом
2. Ввести команду docker-compose build --no-cache backend
3. После ввести команду docker-compose build --no-cache backend (или docker-compose up -d)
